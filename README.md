# 🍰 CAKE

### Premium Interactive Cake Experience

**Created by Jagdish Bhai**

CAKE is a modern, premium and interactive cake website designed to make discovering and customizing cakes feel like a luxury digital experience.

The website combines beautiful cake photography, smooth slow-motion animations, flavour discovery, cake customization, shopping-cart interactions, responsive navigation and an elegant premium interface.

# ♿ Accessibility

The interface should support:

- Keyboard navigation
- Readable contrast
- Semantic HTML
- Accessible buttons
- Image alt text
- Mobile accessibility
- Reduced motion preferences

# 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/jagdishmaliwad2002/Cake.git
```

Enter the project:

```bash
cd Cake
```

Run a local server:

```bash
python3 -m http.server 8080
```

Open:

```text
http://localhost:8080
```
